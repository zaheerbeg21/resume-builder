# T-037: Wire `LlmProvider` into `/api/ai/bullet-optimize` with Guard Retry, Quotas & Telemetry

## 1. Goal
Replace the deterministic local generator `generateDeterministicBulletResult` in `app/api/ai/bullet-optimize/route.ts` with `LlmProvider.generateStructured` backed by `BULLET_OPTIMIZE_SYSTEM_PROMPT` (Blueprint §6.3), enforce `verifyZeroInventedDigits` and `verifyWordCount` with a single structural retry before failing with HTTP `422`, enforce per-user rate limits and AI quotas, and record one `usage_events` telemetry row per request.

## 2. Owner Role and Test Author
- **Owner Role:** Backend Engineer
- **Test Author:** Backend Engineer / QA Engineer

## 3. Allowed Files
- `docs/tickets/T-037.md`
- `lib/ai/prompts/bullet-optimize.ts`
- `app/api/ai/bullet-optimize/route.ts`
- `tests/ai/bullet-optimize.test.ts`

## 4. Acceptance Criteria
1. `lib/ai/prompts/bullet-optimize.ts` exports `BULLET_OPTIMIZE_PROMPT_VERSION = 'v2'`, static `BULLET_OPTIMIZE_SYSTEM_PROMPT` (Blueprint §6.3), and collision-safe `buildBulletPrompt(input, retryFeedback?)` wrapping the untrusted JSON payload in `<<<BULLET_SOURCE_BOUNDARY>>>`.
2. `app/api/ai/bullet-optimize/route.ts` exports `PROMPT_VERSION`, `setProviderForTesting`, and `resolveDefaultProvider()` (failing closed with `503` when `GEMINI_API_KEY` is unset; zero fallback to `FakeProvider` or template strings).
3. `POST /api/ai/bullet-optimize` enforces `10/60s` rate limit (`429` + `Retry-After: 60`) and `5/24h` free / `300/30d` pass AI quota (`429`), runs `verifyZeroInventedDigits` and `verifyWordCount(variant.text, 12, 32)` on all 3 variants with at most 1 retry (`422` on persistent guard failure), maps `ProviderError` (`timeout` -> `504`, others -> `502`), and records exactly 1 `usage_events` row per request.
4. Dead code `generateDeterministicBulletResult` and `cleanCoreText` removed after verifying zero external callers.
