# T-011: PDF Templates: Refine standard.tsx & Implement Classic Serif Template

## 1. Goal
Refine the initial `standard.tsx` template from the T-001 spike into production-grade ATS single-column design, implement the `classic.tsx` serif template with embedded static serif fonts, and verify dual-template extraction fidelity via QA test harness.

## 2. Owner Role & Test Author
- **Owner Role:** Document Engineer
- **Test Author:** QA Engineer (QA writes template extraction tests *before* final styling adjustments)

## 3. Allowed Files
- `lib/pdf/templates/standard.tsx` (Production Standard template using Inter sans-serif)
- `lib/pdf/templates/classic.tsx` (Classic template using embedded static serif font)
- `lib/pdf/fonts.ts` (Font registration module for Inter and Serif fonts)
- `lib/pdf/styles.ts` (Shared ATS-compliant styling tokens: margins, line-heights, point sizes)
- `public/fonts/SourceSerif4-Regular.ttf` (Static regular serif font)
- `public/fonts/SourceSerif4-Bold.ttf` (Static bold serif font)
- `tests/pdf-templates.test.ts` (Dual-template render and extraction test suite)

## 4. Human-Only Prerequisites
- Human approval of selected serif font (e.g., Source Serif 4 or Noto Serif) and confirmation of its open-source license (SIL Open Font License).

## 5. New Dependencies for Human Approval
- None (static `.ttf` font files committed to `public/fonts/`; no runtime packages).

## 6. Dependencies
- T-001 (PDF round-trip spike)
- T-003 (Core Resume Schema)

## 7. Acceptance Criteria
1. **Refined Standard Template (`lib/pdf/templates/standard.tsx`):**
   - Refines the initial spike template into a complete, professional resume layout.
   - Strictly single column. No sidebars, no multi-column grids, no tables, no graphic icons, no avatars.
   - Body typography: 10 pt or 10.5 pt, line-height 1.3 to 1.4.
   - Margins: strictly 0.6 in to 0.75 in (43 to 54 pt).
   - Standard section headings only: Summary, Experience, Projects, Education, Skills.
2. **Classic Serif Template (`lib/pdf/templates/classic.tsx`):**
   - Implements identical structural hierarchy and layout metrics as Standard, styled with the embedded static serif font.
   - Elegant, traditional typographical appearance suited for finance, legal, academia, and executive roles.
3. **Font Registration Updates (`lib/pdf/fonts.ts`):**
   - Registers serif static TTF fonts alongside Inter.
   - On Node.js (SSR / test / export): registered via absolute path `path.join(process.cwd(), 'public', 'fonts', 'SourceSerif4-*.ttf')`.
   - In browser: registered via `/fonts/SourceSerif4-*.ttf`.
   - Global hyphenation callback remains disabled for all registered font families (`(word) => [word]`).
4. **No Replacement Characters (`\uFFFD`):**
   - Both templates render and extract accented characters ("Renée Noël Müller", "Łukasz Żółć") and ligature words ("Certified", "workflow", "office") without unicode replacement characters or garbled glyphs.
5. **QA Test Harness (`tests/pdf-templates.test.ts`):**
   - QA writes tests rendering both Standard and Classic templates using `@react-pdf/renderer`'s `renderToBuffer`.
   - Runs extracted text through `pdf-parse` v2 and verifies 100% heading and date retention in expected order for both templates.
