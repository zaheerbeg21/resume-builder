# T-010: Guided Resume Editor — Part 2: Experience, Projects, & Education

## 1. Goal
Implement the core work history, projects, and educational background sections of the guided resume editor, providing specialized card components, start/end date inputs with "current role" logic, and bullet management with strict length constraints.

## 2. Owner Role & Test Author
- **Owner Role:** Frontend Engineer
- **Test Author:** Frontend Engineer

## 3. Allowed Files
- `components/editor/ExperienceSection.tsx` (Work experience list container and add/reorder actions)
- `components/editor/ExperienceCard.tsx` (Individual work experience item card with date logic)
- `components/editor/ProjectsSection.tsx` (Key projects list container and card item)
- `components/editor/EducationSection.tsx` (Education background credentials container and item)
- `components/editor/BulletListInput.tsx` (Reusable bullet points list input with character validation)
- `tests/components/editor-part2.test.tsx` (Component tests for experience, projects, and education)

## 4. Human-Only Prerequisites
- None.

## 5. New Dependencies for Human Approval
- None.

## 6. Dependencies
- T-009 (Zustand store and Editor Part 1)

## 7. Acceptance Criteria
1. **Work Experience Section (`components/editor/ExperienceSection.tsx`):**
   - Displays list of work experience cards.
   - Allows adding a new role, removing an existing role, and reordering roles up/down.
2. **Experience Card Logic (`components/editor/ExperienceCard.tsx`):**
   - Inputs for `company`, `title`, `location`, `start` date (`YYYY` or `YYYY-MM`), and `end` date.
   - `current` role checkbox: when checked, clears `end` date, disables the end date input field, and sets `current = true` in the store.
   - Seamlessly integrates `BulletListInput`.
3. **Bullet List Management (`components/editor/BulletListInput.tsx`):**
   - Dynamic list supporting adding, removing, and editing bullet strings.
   - Enforces a maximum of 8 bullets per experience entry (disables "Add Bullet" when 8 reached).
   - Enforces maximum 300 characters per individual bullet; renders character counter and turns red when exceeding 300.
   - Prevents bullet glyph characters (`•`, `-`, `*`) from being pasted or typed at the start of bullets.
4. **Projects Section (`components/editor/ProjectsSection.tsx`):**
   - Allows adding/removing projects with `name`, optional project `url`, and up to 5 bullet points.
5. **Education Section (`components/editor/EducationSection.tsx`):**
   - Allows adding/removing educational entries with `school`, `degree`, `start` date, and `end` date.
6. **Store Integration:**
   - All input changes dispatch updates to the Zustand store and trigger debounced autosave.
7. **Component Tests (`tests/components/editor-part2.test.tsx`):**
   - Asserts toggling "current role" disables and clears the end date field.
   - Asserts adding more than 8 bullets is prevented.
   - Asserts typing more than 300 characters in a bullet displays validation error.
