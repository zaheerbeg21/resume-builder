# T-022: Layout-Aware Spatial Stream & Cross-Column Alignment Extractor (Conditional Stage 2)

## 1. Goal
Implement `lib/pdf/layout-extractor.ts` using direct `pdfjs-dist` text stream extraction. Convert raw PDF character positions into a spatially normalized, reading-order text stream that preserves vertical alignment across multi-column layouts (avoiding independent column sorting). Employ relative thresholds based on median line height and page width, handle multi-page repeated headers/footers, normalize superscripts, and mark header lines larger or bolder than the body median without polluting the stream with per-item tag markers.

*Staging Note:* This ticket is conditional (Stage 2). It will only be implemented if Stage 1 plain-text extraction fails to achieve multi-column accuracy thresholds on T-016 fixtures.

## 7. Acceptance Criteria
1. **Vertical Alignment Preservation (No Independent Column Sorting):**
   - Merges text items into horizontal bands using a relative vertical clustering threshold: $\Delta y \le 0.35 \times H_{\text{med}}$ *(starting value tuned on the corpus)*.
   - Within each $y$-band, items are sorted by $x$-coordinate and joined with delimiter ` | `. Guarantees that right-column dates align with left-column job titles on the same row.
2. **Relative Column Gutters:**
   - Detects column white-space gaps using relative page-width threshold: $\text{gap} \ge 0.03 \times W_{\text{page}}$ *(starting value tuned on the corpus)*.
3. **Typography Hints (No Per-Item Tags):**
   - Lines with median font size $> 1.2 \times \text{bodyMedianSize}$ or bold font weights are prefixed with `# ` to designate section headers.
   - Does not emit noisy per-item tags (e.g. no inline `[FONT:12]` or `[COL:left]` tokens).
4. **Multi-Page & Flow Normalization:**
   - Repeated headers/footers appearing in the top or bottom 5% across consecutive pages are detected and stripped.
   - Rotated text is normalized or excluded from the main body stream.
   - Superscripts ($< 0.75 \times H_{\text{med}}$ sharing the baseline) are collapsed inline without line splitting.
