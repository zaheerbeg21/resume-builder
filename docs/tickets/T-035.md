# T-035: Render Projects Section in Standard PDF Template

## 1. Goal
Render the `Projects` section in `lib/pdf/templates/standard.tsx` (`ResumeDocument`) directly between `Experience` and `Education`, matching `STANDARD_SECTION_ORDER` in `lib/pdf/lint.ts` and `lib/pdf/templates/classic.tsx`, so standard-template exports include user projects and pass ATS lint.

## 2. Owner Role and Test Author
- **Owner Role:** Document Engineer
- **Test Author:** Document Engineer / QA Engineer

## 3. Allowed Files
- `docs/tickets/T-035.md`
- `lib/pdf/templates/standard.tsx`
- `tests/pdf-roundtrip.test.ts`

## 4. Acceptance Criteria
1. `styles.projectName` (`{ fontSize: 10.5, fontWeight: 'bold' }`) is added to `lib/pdf/templates/standard.tsx`.
2. `ResumeDocument` renders the `Projects` section strictly between `Experience` and `Education` only when `resume.projects && resume.projects.length > 0`.
3. Heading text is literally `Projects` (single-column, no text transform, no tables, no icons), rendering each `proj.name` and `proj.bullets` with `entry` / `bulletRow` / `bulletDot` / `bulletText`.
4. `pdf-parse` v2 round-trip tests verify reading order between `Experience` and `Education`, `lintExtractedText()` pass, and omission when `projects` is `[]`.
