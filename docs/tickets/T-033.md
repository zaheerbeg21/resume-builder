# T-033: Stage-1 Import UI Wiring & Draft Review

## 1. Goal
Wire `ImportResumeDialog` to the T-020/T-025 3-step signed-URL upload, async `202` enqueue, and job status polling pipeline, and upgrade `ImportReviewModal` to safely handle nullable `ResumeImportDraft` fields, `EXCEEDS_LENGTH_LIMIT` notices, `UNSLOTTED_CONTENT` excerpts, and client-side `ResumeSchema` validation prior to saving.

## 2. Owner Role and Test Author
- **Owner Role:** Frontend Engineer
- **Test Author:** Frontend Engineer / QA Engineer

## 3. Allowed Files
- `components/import/ImportResumeDialog.tsx`
- `components/import/ImportReviewModal.tsx`
- `tests/import-ui.test.ts`
- `docs/tickets/T-033.md`

## 4. Dependencies
- Prerequisites: T-020 (`POST /api/resumes/upload-url`), T-021 (`ResumeImportDraft`), T-025 (`POST /api/ai/parse-resume`, `GET /api/ai/parse-resume/status/[id]`).

## 5. Acceptance Criteria
1. **3-Step Upload & Polling Pipeline (`ImportResumeDialog`):**
   - `mode === 'upload'` requests `POST /api/resumes/upload-url`, handles `429` (with `Retry-After`) and `503`/non-OK errors without attempting Storage PUT, uploads the PDF via `PUT signedUrl` (`Content-Type: application/pdf`, `x-upsert: false`), enqueues via `POST /api/ai/parse-resume` with `{ storagePath }`, and polls `GET pollUrl` every `2000ms` (up to `90_000ms`).
   - Renders accessible `aria-live="polite"` progress states (*"Uploading PDF..."*, *"Queued for extraction..."*, *"Extracting resume details..."*).
   - Opens `ImportReviewModal` on `completed`, opens `scanAlert` on `failed` with `isScan`, and surfaces clean recovery guidance on terminal failure.
   - Cleans up active requests/timers via `AbortController` on close or unmount, while keeping `mode === 'paste'` intact.
2. **Draft Normalization & Review Flags (`ImportReviewModal`):**
   - Accepts `ResumeImportDraft | ResumeParserOutput` and normalizes nullable fields to `''` without inventing placeholders.
   - Highlights missing `basics.fullName` and `basics.email` alongside `low_confidence_paths`.
   - Renders `EXCEEDS_LENGTH_LIMIT` notices and an *"Additional Unslotted Content"* section for `UNSLOTTED_CONTENT` excerpts.
   - Validates sanitized resume with `ResumeSchema.safeParse` before `POST /api/resumes`.
