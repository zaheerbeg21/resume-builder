# T-036: Wire `LlmProvider` into `/api/jd/analyze` with Cache Key, Quotas & Telemetry

## 1. Goal
Replace the deterministic regex placeholder `extractJdLocally` in `app/api/jd/analyze/route.ts` with `LlmProvider.generateStructured` backed by `JD_ANALYZE_SYSTEM_PROMPT` (Blueprint §6.2), update `computeJdHash` to key on `(jdText, PROMPT_VERSION, provider, model)`, enforce per-user rate limits and AI quotas on cache misses, and record `usage_events` telemetry.

## 2. Owner Role and Test Author
- **Owner Role:** Backend Engineer
- **Test Author:** Backend Engineer / QA Engineer

## 3. Allowed Files
- `docs/tickets/T-036.md`

## 4. Acceptance Criteria
1. `lib/ai/prompts/jd-analyze.ts` exports `JD_ANALYZE_PROMPT_VERSION = 'v2'`, static `JD_ANALYZE_SYSTEM_PROMPT` (Blueprint §6.2), and collision-safe `buildJdPrompt(jdText)`.
2. `computeJdHash` hashes `${normalized}:${version}:${provider}:${model}` and `PROMPT_VERSION` re-exports `JD_ANALYZE_PROMPT_VERSION`.
3. `POST /api/jd/analyze` fails closed with `503` when unconfigured (zero silent fallback to `FakeProvider` or `extractJdLocally`), returns `X-Cache: HIT` on memory/`jd_targets` hits without consuming quota or calling the LLM, enforces `10/60s` rate limit and `5/24h` free (`300/30d` pass) quota on cache misses, maps `ProviderError` (`timeout` -> `504`, others -> `502`), and records `usage_events` telemetry.
4. Dead code `KNOWN_KEYWORDS` and `extractJdLocally` removed from `app/api/jd/analyze/route.ts` after verifying zero external callers.
