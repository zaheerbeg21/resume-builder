# T-029: DMCA Compliance: Designated Agent Page & Notice-and-Takedown Workflow

## 1. Goal
Implement a dedicated public `/dmca` route (`app/(marketing)/dmca/page.tsx`), link it in `components/marketing/Footer.tsx`, and draft a statutory notice-and-takedown procedure complying with the Digital Millennium Copyright Act (17 U.S.C. § 512). The page must establish safe harbor protections for the platform by publishing required statutory notice elements (§ 512(c)(3)), counter-notification requirements (§ 512(g)), and a repeat-infringer termination policy. All designated agent contact fields must be rendered using `[OWNER: ...]` placeholders, accompanied by a prominent disclaimer: *"Notice: Lawyer review required prior to publication."* Include a step-by-step walkthrough for the owner to register the agent in the U.S. Copyright Office online directory, explicitly tagging all fees and renewal intervals with *"verify on copyright.gov"*.
