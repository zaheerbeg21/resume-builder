# T-007: Auth UI & Sign-In/Sign-Up Pages

## 1. Goal
Build accessible, responsive, and polished frontend pages for user authentication, providing seamless email/password registration, login, and Google OAuth single sign-on flows.

## 2. Owner Role & Test Author
- **Owner Role:** Frontend Engineer
- **Test Author:** Frontend Engineer

## 3. Allowed Files
- `app/(auth)/login/page.tsx` (Login page layout and metadata)
- `app/(auth)/register/page.tsx` (Registration page layout and metadata)
- `components/auth/LoginForm.tsx` (Email/password login form component)
- `components/auth/RegisterForm.tsx` (Email/password registration form component)
- `components/auth/OAuthButtons.tsx` (Google OAuth button component)
- `tests/components/auth.test.tsx` (Component unit and interaction tests)

## 4. Human-Only Prerequisites
- None.

## 5. New Dependencies for Human Approval
- None.

## 6. Dependencies
- T-006 (Auth session handling and callback route)

## 7. Acceptance Criteria
1. **Login Page (`app/(auth)/login/page.tsx`):**
   - Renders a clean, centered authentication card with title, subtitle, `LoginForm`, and `OAuthButtons`.
   - Links to `/register` for users without an account.
   - Respects `returnTo` search parameter on successful login.
2. **Registration Page (`app/(auth)/register/page.tsx`):**
   - Renders registration card with `RegisterForm` and `OAuthButtons`.
   - Links to `/login` for existing users.
3. **Form Validation & UX:**
   - Validates email format before submission.
   - Enforces password length of at least 8 characters.
   - Shows clear, accessible error messages upon auth failure (e.g., "Invalid credentials", "User already registered").
   - Displays disabled states and loading spinners on submit buttons during inflight requests.
4. **Google OAuth SSO:**
   - `OAuthButtons` triggers `supabase.auth.signInWithOAuth({ provider: 'google', options: { redirectTo: ... } })`.
   - Handles OAuth initiation errors cleanly.
5. **Accessibility (a11y):**
   - Proper `<label>` elements linked to inputs with matching `htmlFor` and `id`.
   - Error messages associated with inputs via `aria-describedby` and `aria-live="polite"`.
   - Full keyboard navigation support (Tab order, Enter to submit).
6. **Component Tests (`tests/components/auth.test.tsx`):**
   - Asserts login form renders inputs and submit button.
   - Asserts validation errors render when submitting invalid email.
   - Asserts Google OAuth button triggers OAuth sign-in call with correct callback parameters.
