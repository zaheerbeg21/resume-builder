# T-004: Supabase Database Migrations (`profiles`, `resumes`, Auth Trigger, 5-Resume Limit)

## 1. Goal
Create idempotent PostgreSQL schema migrations defining `profiles` and `resumes` tables in Supabase, configure an automated trigger syncing new `auth.users` records to `profiles`, and implement a database-level trigger enforcing the hard limit of 5 resumes per user.

- **Test Author:** Database & Security Engineer

## 7. Acceptance Criteria
1. **`profiles` Table Migration:**
   ```sql
   create table profiles (
     id uuid primary key references auth.users on delete cascade,
     created_at timestamptz default now()
   );
   ```
2. **`auth.users` → `profiles` Sync Trigger:**
   - Creates a trigger function `public.handle_new_user()` executing with `security definer`.
   - Fires on `after insert on auth.users for each row`.
   - Inserts `new.id` into `public.profiles`.
3. **`resumes` Table Migration:**
   ```sql
   create table resumes (
     id uuid primary key default gen_random_uuid(),
     user_id uuid not null references profiles(id) on delete cascade,
     title text not null,
     template text not null default 'standard',
     content jsonb not null,
     schema_version int not null default 1,
     updated_at timestamptz default now()
   );
   ```
4. **Database-Enforced 5-Resume Limit:**
   - Creates a trigger function `public.enforce_resume_quota()` firing on `before insert on resumes for each row`.
   - Checks `count(*) from resumes where user_id = new.user_id`.
   - If count is $\ge 5$, raises an exception: `'Quota exceeded: Users may not create more than 5 resumes.'` (code `P0001`).
5. **Updated At Trigger:** Updates `updated_at = now()` automatically on any row update on `resumes`.
6. **Integration Tests (`tests/db/schema.test.ts`):**
   - Asserts inserting a mock user into `auth.users` creates the corresponding `profiles` row.
   - Asserts inserting 1 to 5 resumes for a single user succeeds.
   - Asserts attempting to insert a 6th resume for the same user is rejected by the database engine with the expected quota exception.
   - Asserts deleting a user cascades and removes their profile and all associated resumes.
