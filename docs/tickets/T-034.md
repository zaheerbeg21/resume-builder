# T-034: PDF Export Entitlement Gate & Billing Hardening

## 1. Goal
Propagate `userId` onto Stripe PaymentIntent/Charge metadata for refund/dispute revocation, fail fast in production when `SUPABASE_SERVICE_ROLE_KEY` is missing, and enforce Blueprint §3 & §8 PDF export quotas (1 free clean export, unlimited exports with an active 30-day pass, zero charge when ATS lint fails).

## 2. Owner Role and Test Author
- **Owner Role:** Backend Engineer
- **Test Author:** Backend Engineer / QA Engineer

## 3. Allowed Files (Authorized Seven-File Scope)
- `docs/tickets/T-034.md`
- `lib/billing/stripe.ts`
- `lib/billing/entitlements.ts`
- `app/api/pdf/export/route.ts`
- `tests/billing/billing.test.ts`
- `tests/pdf/export.test.ts`
- `tests/pdf/classic-template.test.ts` (authorized exclusively to wire `setServiceRoleClientForTesting` in the `exportPdfRoute` test)

## 4. Acceptance Criteria
1. `createCheckoutSession()` includes `payment_intent_data[metadata][userId]` alongside `metadata[userId]`.
2. `getServiceRoleClient()` throws `Missing required environment variable: SUPABASE_SERVICE_ROLE_KEY` when `NODE_ENV === 'production'` and the key is missing or blank, while preserving `setServiceRoleClientForTesting()` and non-production test defaults.
3. `POST /api/pdf/export` checks `hasActivePass(user.id)`:
   - Free users (`!hasActivePass`): queries `usage_events` for `/api/pdf/export`; fails closed with HTTP `503` on query error; blocks with HTTP `402` (`EXPORT_LIMIT_REACHED`) when `count >= 1`.
   - Failed ATS lint (`422`) never records a `usage_events` row.
   - Clean export (`200`) records a `/api/pdf/export` telemetry row via `recordUsageEvent()`.
