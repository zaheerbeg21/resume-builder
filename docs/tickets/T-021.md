# T-021: `ResumeImportDraft` Schema & Review-Stage Ripple Isolation

## 1. Goal
Define `ResumeImportDraftSchema` in `lib/ai/schemas.ts` as an explicit staging contract for resume imports. Allow missing extracted fields (`company`, `title`, `school`, `degree`, `email`) to be `null` rather than generating fabricated placeholder strings. Implement non-truncating bounds that preserve full imported text while flagging entries that exceed `ResumeSchema` limits (summary $> 600$ chars, $> 8$ bullets per role, $> 5$ links). Document and isolate ripple effects across the editor review modal.

## 2. Owner Role and Test Author
- **Owner Role:** Backend Engineer
- **Test Author:** QA Engineer (QA writes schema validation, boundary, and non-truncation tests first)

## 3. Allowed Files
- `lib/ai/schemas.ts`
- `types/resume.ts`
- `tests/resume-draft-schema.test.ts`

4. **Clean Separation:**
   - `ResumeImportDraftSchema` is a staging contract only and does not loosen `ResumeSchema`. The strict `ResumeSchema` remains the one used for database persistence and PDF export.

## 5. New Dependencies for Human Approval
- None.

## 6. Dependencies
- Feeds: T-023 (Provenance Guard), T-024 (LLM Parser Adapter), T-025 (Route Handler).

## 7. Acceptance Criteria
1. **Nullable Fields:**
   - `basics.fullName`, `basics.email`, `basics.phone`, `experience[].company`, `experience[].title`, `education[].school`, and `education[].degree` accept `null` without throwing Zod validation errors.
2. **Non-Truncating Bound Preservation:**
   - Summaries exceeding 600 characters are preserved completely in the payload; an issue is recorded in `review_flags` (`reason: 'EXCEEDS_LENGTH_LIMIT'`).
   - Experience items exceeding 8 bullets are preserved completely with a corresponding `review_flag`.
   - Links exceeding 5 items are preserved completely with a corresponding `review_flag`.
3. **Telemetry & Warnings:**
   - Includes `warnings: z.array(z.string())` and `low_confidence_paths: z.array(z.string())`.
4. **Clean Separation:**
   - `ResumeSchema` in `types/resume.ts` remains unmodified, preserving strictness for database persistence and PDF export.
