# T-003: Core Resume Zod Schema & TypeScript Types

## 1. Goal
Define the comprehensive, single source of truth for resume data structure using Zod 4 and TypeScript strict types, enforcing data integrity across the frontend editor, backend API routes, database JSONB storage, and PDF rendering engine.

## 2. Owner Role & Test Author
- **Owner Role:** Solution Architect
- **Test Author:** Solution Architect

## 3. Allowed Files
- `types/resume.ts` (schema definitions and inferred TypeScript types)
- `tests/types/resume.test.ts` (unit tests validating schema constraints and edge cases)

## 4. Human-Only Prerequisites
- None.

## 5. New Dependencies for Human Approval
- None (uses installed `zod` ^4.6.7).

## 6. Dependencies
- T-001 (Extends and completes the minimal `types/resume.ts` interface contract established in T-001 without breaking existing exported types or schema).

## 7. Acceptance Criteria
1. **Zod 4 Syntax Compliance:** Uses modern Zod 4 top-level validators `z.email()` and `z.url()` instead of deprecated `z.string().email()` or `z.string().url()`.
2. **Date Format (`YearMonth`):** Defines `YearMonth = z.string().regex(/^[0-9]{4}(-[0-9]{2})?$/).nullable()`, accepting `YYYY` (e.g., `"2024"`), `YYYY-MM` (e.g., `"2024-06"`), or `null`.
3. **Sections Implemented:**
   - `basics`: `fullName` (min 1 char), `headline` (default `""`), `email` (`z.email()`), `phone` (optional), `location` (optional), `links` (array of `{ label: string, url: z.url() }`, max 5, default `[]`).
   - `summary`: string, max 600 characters, default `""`.
   - `experience`: array of objects containing `id` (string), `company` (string), `title` (string), `location` (optional string), `start` (`YearMonth`), `end` (`YearMonth`), `current` (boolean, default `false`), and `bullets` (array of strings, max 8 bullets, max 300 characters per bullet).
   - `projects`: array of objects containing `id` (string), `name` (string), `url` (optional `z.url()`), and `bullets` (max 5 bullets, max 300 characters each).
   - `education`: array of objects containing `id` (string), `school` (string), `degree` (string), `start` (`YearMonth`), and `end` (`YearMonth`).
   - `skills`: array of objects containing `group` (string, e.g. "Languages") and `items` (array of strings).
4. **Type Exports:** Exports `ResumeSchema` and inferred type `Resume = z.infer<typeof ResumeSchema>`.
5. **Validation Test Suite (`tests/types/resume.test.ts`):**
   - Validates minimal resume object with default values.
   - Validates comprehensive multi-role resume fixture.
   - Rejects invalid emails (e.g., `not-an-email`) with clear error message.
   - Rejects invalid URLs in links and projects.
   - Rejects more than 8 bullets in an experience entry.
   - Rejects bullets exceeding 300 characters.
   - Rejects summaries exceeding 600 characters.
   - Rejects invalid date strings (e.g. `"June 2024"` or `"2024/06"`).
