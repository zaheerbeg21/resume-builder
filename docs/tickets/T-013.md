# T-013: Live PDF Preview Component

## 1. Goal
Integrate a client-side live PDF preview panel into the resume editor page powered by the identical `@react-pdf/renderer` document tree used for export, providing responsive zooming, page navigation, template switching, and debounced re-renders as the user edits.

## 2. Owner Role & Test Author
- **Owner Role:** Frontend Engineer (in collaboration with Document Engineer)
- **Test Author:** Frontend Engineer

## 3. Allowed Files
- `components/preview/ResumePreview.tsx` (Main preview panel component)
- `components/preview/PDFViewerWrapper.tsx` (Client-only dynamic wrapper for React-PDF viewer)
- `app/(app)/resumes/[id]/edit/page.tsx` (Integration of split-pane editor and preview layout)
- `tests/components/preview.test.tsx` (Component rendering and control tests)

## 4. Human-Only Prerequisites
- None.

## 5. New Dependencies for Human Approval
- None.

## 6. Dependencies
- T-009 (Resume editor and Zustand store)
- T-011 (Standard and Classic templates)

## 7. Acceptance Criteria
1. **Identical Render Engine:**
   - Previews render the shared `<ResumeDocument resume={resume} template={template} />` component.
   - Prevents preview-vs-export layout divergence by sharing identical layout primitives and font registrations.
2. **Client-Only Dynamic Loading:**
   - Wraps the React-PDF preview in a Next.js dynamic import (`dynamic(() => import('./PDFViewerWrapper'), { ssr: false })`) to eliminate SSR window/canvas errors during build or server rendering.
   - Displays a clean loading skeleton while the client PDF canvas initializes.
3. **Responsive Zoom & Navigation Controls:**
   - Zoom controls: Fit Width, 100%, Zoom In (+), Zoom Out (-).
   - Page counter displaying current page and total page count (e.g., "Page 1 of 2").
4. **Template Switching:**
   - Allows switching between 'Standard' (Inter) and 'Classic' (Serif) with immediate preview update.
5. **Debounced Re-render:**
   - Uses `usePDF` or debounced state propagation so rapid keystrokes in the editor do not trigger stuttering canvas re-renders (recommended 400ms preview debounce).
6. **Component Tests (`tests/components/preview.test.tsx`):**
   - Asserts preview container mounts on the client without errors.
   - Asserts template switcher triggers document re-render with the selected template prop.
   - Asserts zoom controls update zoom state.
