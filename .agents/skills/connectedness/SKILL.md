# Connectedness UX Law

Use for timelines, steppers, process flows, dashboards, and grouped controls. Use connectors, alignment, proximity, and shared containers to communicate real relationships. Distinguish states with labels or icons as well as color. Avoid false dependencies and broken connectors at responsive sizes. Provide a linear textual alternative for complex diagrams.
