# Parkinson's Law UX

Use for registration, checkout, search, and onboarding. Ask only for information needed now; use safe autofill and defaults; group related fields; preserve input after errors; and explain sensitive requests. Never guess high-impact data, hide costs, or remove consent/security steps. Validate completion, time, error rate, and abandonment.
