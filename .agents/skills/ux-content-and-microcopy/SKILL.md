# UX Content and Microcopy

Use this skill for button labels, onboarding, forms, empty states, errors, permissions, confirmations, and notifications.

## Principles
- Use plain language and specific action verbs.
- Make labels describe the outcome, not the implementation.
- Explain what happened, why it matters, and how to recover from errors.
- Keep terminology consistent across screens.
- Make irreversible actions and consequences explicit.
- Explain why optional or sensitive information is requested.
- Avoid blame, vague errors, fake urgency, and unsupported promises.

## Review checklist
- Can users predict what happens after the primary action?
- Are required and optional fields clear?
- Are examples and formats provided before errors occur?
- Does an error preserve user input and explain recovery?
- Are success messages specific and actionable?
- Is the language localizable and suitable for assistive technology?

## Output
Provide original text, proposed text, rationale, and any localization/context notes.
