# Choice Overload UX Law

Use for settings, plans, filters, onboarding, and navigation. Group options, show common choices first, explain differences, use safe defaults, and progressively disclose advanced choices. Do not remove user control or hide trade-offs. Use search/filtering for large catalogs. Validate decision time, confidence, and mis-selection.
